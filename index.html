使用场景

远程协作与资料访问

跨地区开会、同步网盘或访问指定办公站点时，优先看稳定性和同时在线设备数。单人笔记本加手机，基础版的 3 台设备通常够用；经常有备用机或平板同时在线，再考虑旗舰版。

流媒体与日常浏览

只做网页和基础视频，基础版列出的基础流媒体解锁即可作为起点。若多个平台都要原生解锁，旗舰版写明了全节点原生流媒体解锁，更适合作为对照项，而不是默认人人需要。

游戏与低抖动需求

游戏在意的是高峰时段的抖动和丢包，不只是标称带宽。旗舰版包含 IPLC 专线游戏加速优化。没有这项需求时，不必为线路名称支付差价。

家庭多设备与小团队

家人分账号共用，或小型工作室需要统一路由，应直接看团队版的 20 台设备、高带宽节点、企业定制路由和客户经理。把个人旗舰版反复加设备，通常不如一次核对团队版边界。

客户端选择

本页重点是客户端，而不是堆节点名称。加速器客户端负责导入订阅、选择线路和按规则分流。一个系统只保留一个主客户端，可减少虚拟网卡冲突。安装包入口均为页内说明，不放置来源不明的直链。

Windows

适合台式机和笔记本。建议使用 Clash 系客户端作为主程序，在规则模式下导入订阅。系统版本以 Windows 10 及以上为核对起点，安装时允许所需的网卡组件。

Windows 官方下载说明：以订购后账户内给出的客户端名称为准，核验系统位数。不要安装名称含破解、绿化或一键提权的二次打包。

macOS

可选 Clash Verge 或 ClashX 一类客户端。首次打开若被系统拦截，到系统设置中确认来源后再启动，不要同时开两个菜单栏代理。

macOS 官方下载说明：核对芯片类型与客户端要求是否一致，再导入订阅。本页不提供外部镜像。

Android

常见选择是 Clash Meta for Android。安装后授予 VPN 连接权限，只开启一个订阅配置，避免与系统自带加速开关叠用。

Android 官方下载说明：从你信任的商店或订购指引获取，拒绝要求额外短信验证码的安装页。

iOS

可使用应用商店中的 Shadowrocket、Stash 等客户端，以上架情况为准。不要安装来源不明的描述文件，也不要相信“免签直装加速器”。

iOS 官方下载说明：在对应商店搜索客户端名称，登录商店账号后安装。订阅仍在客户端内从链接导入。

怎么决定用哪一个

先看操作系统，再看你是否需要规则分流。只在一台电脑上使用，Windows 或 macOS 客户端即可；手机临时使用，再加对应移动客户端，并计入方案的同时在线设备数。iOS 以商店上架为准，不能用安卓安装包替代。

操作说明

  1. 在方案区按设备数和用途选定基础版、旗舰版或团队版，并确认按月或按年。
  2. 订购完成后，从账户中的订阅信息复制完整地址。该地址只供自己的客户端使用，不要发到公开页面或群聊。
  3. 回到客户端选择，阅读对应系统的官方下载说明，只安装一个主客户端。
  4. 在客户端中选择从链接导入或添加订阅，粘贴地址并更新。更新成功后应能看到线路列表。
  5. 先用普通网页做连通性检查。有流媒体或游戏需求时，再按方案切换到对应线路，不要同时启用多个全局代理。
  6. 若无法连接，退出其他代理软件后重试，并核对系统时间。仍失败时，按所购方案的支持方式联系；旗舰版为优先工单，团队版为客户经理。

性能不靠页面上的虚构测速数字说明。选线路时看三件事：你所在时段是否能稳定打开目标站点、流媒体是否按方案解锁、游戏或会议时是否出现持续卡顿。标称带宽不能代替这三项。

基础版使用普通线路节点池，适合一般浏览。旗舰版在此之外写明全节点原生流媒体解锁和 IPLC 游戏优化。团队版强调高带宽与定制路由。若某一项在你的方案卡里没有出现，就不要默认包含。

常见问题

机场测评和单独搜索 VPN 有什么不同？

机场测评把订阅方案、加速器客户端和官网下载说明放在一起核对。单独搜索 VPN 或梯子，容易只看到名称，看不到设备数、流量和线路类型。已经有使用习惯的读者，可以用本页三档方案做边界对照，而不是再追加一层重复名称。

为什么要先选客户端再买长期订阅？

订阅能否使用，取决于客户端与系统是否匹配。Windows、macOS、Android 和 iOS 的安装来源、权限和分流方式不同。先确定主客户端，再决定月付或年付，可以避免买了流量却没有可用程序。

订阅地址应该怎样导入？

在主客户端的订阅或配置页选择从链接导入，粘贴账户给出的完整地址并更新。成功后在线路列表中选择一条做网页检查。若失败，先确认地址没有被截断，且没有第二个代理软件同时运行，然后再更新一次。

基础版、旗舰版和团队版如何取舍？

不超过 3 台设备、以浏览和基础流媒体为主，看基础版。需要 300GB、5 台设备、原生流媒体和游戏向 IPLC，看旗舰版。20 台设备以内的多人共用、高带宽和定制路由，看团队版。年付分别为 ¥150、¥350 和 ¥850。

官网下载时要避开什么？

只按本页对应系统的官方下载说明核对客户端名称和系统版本。不要使用来路不明的破解加速器，也不要在要求额外密码、短信验证码或描述文件的页面继续。本页没有登录表单，下载入口都是页内锚点。

流量用尽或暂时连不上怎么处理？

流量按方案周期计算，用尽后等待刷新或改选更高档，页面不承诺临时加量。连不上时依次检查订阅是否更新、系统时间、所选线路，以及其他代理是否退出。旗舰版可走优先工单，团队版联系客户经理，基础版按账户内的普通支持方式处理。
